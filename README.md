## 🚀 Proyectos destacados
 
### 🌱 [NodoVerde](https://nodoverde.com.ar)
Plataforma IoT para huertas: dispositivos ESP32 que miden temperatura y humedad en tiempo real.
 
[![CI](https://github.com/Reiseng/urban-garden-api/actions/workflows/dotnet.yml/badge.svg)](https://github.com/Reiseng/urban-garden-api/actions/workflows/dotnet.yml)
 
- API REST en **ASP.NET Core 9** con **PostgreSQL** y **EF Core**.
- Autenticación **JWT** con refresh tokens rotativos, roles por parcela y rate limiting.
- Comunicación con los dispositivos por **MQTT** (HiveMQ Cloud): lecturas, configuración remota y comandos.
- Pruebas unitarias con **xUnit** y **Moq**, e integración continua con **GitHub Actions**.
- Frontend en **React + TypeScript**; deploy en Render y Vercel.
### 🧾 [StockControl](https://github.com/Reiseng/stock-manager-wpf)
Sistema de stock, ventas y facturación electrónica para comercios. **En uso real** en un comercio familiar.
 
- Aplicación de escritorio en **C# / WPF (.NET 10)** con arquitectura **MVVM**.
- Integración con **ARCA** (ex AFIP): autenticación con certificado (WSAA) y emisión de comprobantes con CAE (WSFEv1).
- Funciona sin internet: base de datos local **SQLite** y cola de comprobantes pendientes que se reintentan solos.
- Comprobantes en PDF y acceso por roles (administrador, depósito, cajero).
- Instalador y **actualización automática** publicada con GitHub Actions y GitHub Releases.
### 🏋️ Plataforma para centro de entrenamiento · *proyecto freelance*
Registro de usuarios, membresías, reserva de turnos y panel de administración.
- API en **ASP.NET Core (.NET 10)** con Docker, desplegada en Render, y base de datos en Supabase; frontend en React.
### 🏎️ Motor y juego 2D en C++ · *repositorio privado*
Juego de carreras isométrico inspirado en *Rock n' Roll Racing*.
- **C++17**, **SDL3** y **CMake**: gestor de recursos, sistema de entidades, colisiones con SAT y pistas generadas proceduralmente.
- Multijugador en desarrollo con **Steamworks**.
